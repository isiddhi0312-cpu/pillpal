# **App Name**: PillPal: AI Medicine Manager

## Core Features:

- Image-Based Medicine Recognition: Use ML Kit's OCR engine to extract medicine details from photos.
- Manual Entry: Allow users to manually add medicine details if image recognition fails.
- Medicine Schedule Management: Allow users to set time and frequency for medicine intake and edits. Saved locally and in Firebase.
- Reminder Notifications: Trigger local notifications based on the user's schedule.
- Adherence Tracking: Log timestamps of when the user confirms they have taken their medicine.
- Weekly Report Generation: Generate weekly reports on medicine adherence, displayed in a dashboard.
- Intelligent Data Parsing: Employ a rule-based AI tool to parse extracted text into structured data fields, and send the structured data to the user.

## Style Guidelines:

- Primary color: Gentle blue (#64B5F6), evoking trust and calmness.
- Background color: Soft, desaturated blue (#E3F2FD), offering a clean and unobtrusive backdrop.
- Accent color: Muted teal (#4DB6AC) to highlight key actions.
- Font pairing: 'Poppins' (sans-serif) for headlines and short labels, and 'PT Sans' (sans-serif) for body text.
- Use clear and intuitive icons to represent different medicines and actions.
- Clean, card-based layout with ample spacing for easy readability on mobile devices.
- Subtle animations and transitions to confirm actions and provide feedback.
